1. Architecture

Dual-Tier Design

Local MVP (development and testing)

  • Embedding: Ollama nomic-embed-text (768 dims)
  • Store: PostgreSQL 16 with pgvector (from docker-compose)
  • Reranking: Reciprocal Rank Fusion (no external model)
  • Generation: Ollama llama3.1 via local_only tier

Production (API-backed)

  • Embedding: Voyage 3 (1024 dims, 32K token window)
  • Store: PostgreSQL 16 with pgvector (HNSW, m=16, ef_construction=200)
  • Reranking: Voyage Rerank 2 (100 docs, top-10)
  • Generation: Claude Sonnet 4 via rag_specialist tier

3. Hybrid Retrieval

Vector Search

  • Embed query, search HNSW index with cosine distance, return top 2K candidates

Keyword Search

  • PostgreSQL full-text search with plainto_tsquery and pg_trgm trigram index

Reciprocal Rank Fusion

  • Merge both lists: score = sum of 1/(k + rank) across lists, k=60

4. Agentic Loop

Query --> Retrieve (hybrid) --> Grade (LLM-as-judge, 0-1) | relevance < 0.5? / \ yes no | | Rewrite Generate (with [chunk-id] citations) | | (loop, max 3) Self-Check (verify grounding) | Result

7. Eval Hooks

Metrics

  • Retrieval Recall@K: Fraction of relevant chunks in top-K
  • Relevance Score Distribution: Mean and std of LLM-graded relevance
  • Rewrite Rate: Percentage of queries requiring rewrite
  • Citation Coverage: Percentage of answer sentences with a citation
  • Grounding Score: Fraction of claims verifiable against retrieved spans
  • Loop Depth: Average iterations per query

8. Failure Modes

FailureSymptomMitigation
Stale indexRelevant docs not retrievedRe-run make rag-ingest. Add freshness checks.
Retrieval missNo chunks match queryRewrite loop tries alternatives. Returns low_relevance after 3 tries.
Prompt injection via docsIngested doc hijacks instructionsChunker sanitizes tool-trigger patterns. Guardrails validate output.
Embedding model downAPI errors on embedFallback to local Ollama. Zero vectors as last resort.
Budget exhaustionGeneration routed to local_onlyModelRouter budget check. Quality degrades but service continues.
Hallucinated citationsAnswer cites non-existent chunksCitation extractor cross-checks against retrieved IDs.
Prompt injection via ingested documents is the highest-risk failure mode. Treat all document content as untrusted.

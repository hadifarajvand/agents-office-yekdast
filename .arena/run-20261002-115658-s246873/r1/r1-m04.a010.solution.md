## 9. Anything else materially wrong

- **`npm run check` is the most concretely stale claim in the document.** Current real output: `34/38 checks passed — smoke: command bar adds a task in demo mode, smoke: department focus opens the chat rail, smoke: approval flow reaches the panel, server: /api/brain has the live graph`. Three of these four failures (the three smoke-suite ones) are not mentioned anywhere in the plan. Whoever starts Task 7 (contract tests) or Task 8 (E2E smoke) should know the smoke suite is currently failing on three fronts unrelated to anything in this plan's scope, and investigate before assuming a clean baseline.
- **`/api/chat`'s actual response shape is narrower than claimed.** The plan's API contract table (Task 7) states `POST /api/chat` returns `{reply, read, tools, used, interview, routine?, routines?, setup?}` at `main.py:423-452`. The actual handler (`backend/app/main.py:423-451`) returns only `{"reply": reply}` on the LLM path, or `{"reply": ...}` on the routine-command paths — there is no `read`, `tools`, `used`, `interview`, `routine`, `routines`, or `setup` key anywhere in the function. This matters directly for Task 7, whose entire purpose is writing one contract test per route — the test for `/api/chat` needs to assert the real (narrower) shape, not the one in this table, or it will fail on day one.
- **The plan's claimed catch-all 404 behavior doesn't exist.** The contract table's last row says `* | anything else | 404 {error:'not found'} | main.py:454-456`. Lines 454-456 are actually `@app.exception_handler(Exception)` — a *500* handler for uncaught exceptions, not a 404 catch-all. There is no explicit catch-all route in `main.py`; an unmatched path falls through to FastAPI's own default 404 (`{"detail":"Not Found"}`), a different shape than the plan claims. (The three `{"error": "not found"}, status_code=404` responses that do exist in the file — lines 201, 321, 350 — are specific per-route "record not found" checks, not a catch-all.) Task 7's contract test for "anything else" should test FastAPI's actual default shape, not the one cited here.
